# 📘 Placement Lab – Website README (For GitHub Copilot / Developer)

## 🧠 Project Overview
Placement Lab is a career-focused platform that provides **step-by-step placement guidance** and **job-ready courses** for:
- College students  
- Pass-out students  
- Any individual seeking a job  

The platform focuses on **skills over degree**, **real-world training**, and **job readiness**.

---

## 🎯 Core Features

### 🔐 Authentication System
- Login / Signup via **Mobile Number only**
- Simple UI:
  - One input field → Enter mobile number
  - OTP-based authentication (recommended)
- After login:
  - User dashboard accessible
  - Enrolled courses visible
